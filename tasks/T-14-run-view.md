# T-14 Экран рана: граф + панель этапа + стрим-виджет

Статус: todo · M1 · зависимости: T-13

## Цель

Главный экран продукта (D-61) — 80% времени пользователя здесь.

## Раскладка

```
┌────────────────────────────────────────────────────────┐
│ header: задача · проект · ветка · состояние · токены   │
│         [⏸ stop] [⌨ interrupt&steer] [открыть в IDE]*  │
├──────────────┬─────────────────────────────────────────┤
│ ГРАФ xyflow  │ ПАНЕЛЬ ЭТАПА (tabs)                     │
│  (лев. кол.) │ [Стрим] [Артефакты] [Промпт] [Метрики]  │
├──────────────┴─────────────────────────────────────────┤
│ ЧАТ С ПАЙПЛАЙНОМ (гейты) — см. T-15                    │
└────────────────────────────────────────────────────────┘
(* «открыть в IDE» — кнопка с M1, команда из project.ide_command, D-63)
```

## Граф

- Ноды = этапы пайплайна рана; состояния: pending (серый), running
  (пульс-анимация + последние 2-3 строки стрима прямо в ноде), succeeded
  (✓), failed (✗), interrupted (⚠ + счётчик auto-resume), waiting (гейт —
  иконка пользователя).
- Loop-edge рисуется петлёй с подписью `2/4` (итерация/лимит).
- Клик по ноде → панель этапа. Keyboard: j/k — навигация по этапам (D-64).

## Стрим-виджет (критичное требование — живой стрим рассуждений)

- Вход — нормализованные события (D-41), НЕ сырой терминал.
- Рендер: `text` — через Streamdown (streaming markdown, Shiki);
  `thinking` — сворачиваемый блок «рассуждения» (по умолчанию свёрнут после
  завершения, развёрнут во время); `tool_call` — чип (иконка тулзы + имя
  файла/команды, раскрытие → аргументы/результат усечённый); `usage` — в
  метрики; `error` — красная плашка; `raw` — под спойлером «raw output».
- Автоскролл с «прилипанием» (отмотал вверх — не дёргаем); пауза/копия
  выделенного.
- Виртуализация ленты (тысячи событий на этап — react-virtuoso или
  аналог).
- Референсы: es617/claude-replay, hoangsonww/Claude-Code-Agent-Monitor
  (см. обсуждение; посмотреть их подход к рендеру thinking/tool calls).

## Табы панели

- Артефакты: список файлов этапа, просмотр (markdown — рендер, diff — с
  подсветкой; большие файлы — скачать/открыть).
- Промпт: финальный отрендеренный промпт этапа (prompt-<stage>.md).
- Метрики: длительность, токены in/out, число попыток (resume_count).

## Acceptance

- Живой ран виден в реальном времени: пульс, стрим, смена состояний без
  перезагрузки.
- Перезагрузка страницы посреди рана → состояние восстанавливается из
  журнала, стрим догоняется (проверить на ране с 5000+ событий).
- Исторический ран (завершённый) смотрится так же — вся лента из БД.
