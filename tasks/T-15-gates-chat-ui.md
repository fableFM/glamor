# T-15 Чат гейтов + инбокс

Статус: done (2026-08-17) · M1 · зависимости: T-13, T-11 (API гейтов)

## Цель

Нижняя панель экрана рана + глобальный инбокс (D-21/61/64).

## Чат с пайплайном (всегда виден на экране рана)

- Гейт = сообщение в ленте: вопрос планировщика (текст + ссылка на
  questions.md), эскалация петли (выжимка findings), финальный гейт
  (summary рана + кнопки).
- Действия прямо в сообщении: [Approve] [Comment → fix] [Reject/Stop],
  поле ответа для `question`/`escalation`.
- Системные события тоже в ленте (сворачиваемые): «этап code начат»,
  «auto-resume 2/3: сеть», «branch_mismatch!».
- Queue note: поле «заметка к рану» (без прерывания, D-22) + список
  заметок со статусом consumed.
- Interrupt & Steer: поле + кнопка на активном этапе с confirm-диалогом
  («этап будет прерван и возобновлён с вашим сообщением»).
- Keyboard: `a` — approve активного гейта, `c` — фокус на comment (D-64).
- Оптимистичный UI + reconciliation по событию `gate.resolved` (гонка
  двух клиентов: UI и TG — проигравший видит «уже резолвнуто»).

## Глобальный инбокс гейтов

- Доступен из любого экрана (иконка в шапке + бейдж с числом открытых
  гейтов по всем проектам — события `run_id=*`, T-04).
- Список: проект · пайплайн · тип гейта · сколько ждёт · переход к рану.
- Это «живой morning-report» из BRAINSTORM.

## Acceptance

- Сценарий: планировщик задал вопрос → ответ в чате → пайплайн пошёл
  дальше; всё без перезагрузки.
- Два окна UI: resolve в одном мгновенно отражается в другом.
- Инбокс показывает гейты всех проектов, бейдж обновляется live.
