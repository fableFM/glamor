# T-20 Граф-редактор пайплайнов

Статус: todo · M2 · зависимости: T-13, T-21 (модель версий)

## Цель

Красивый визуальный редактор пайплайнов (D-62) на `@xyflow/react`.

## Модель

- Типы нод: `llm-stage` (промпт-шаблон, триплет harness/model/effort,
  depth, human/ai-output, vendor-флаги), `janitor` (команды скрипта,
  T-22), `human-gate` (текст/инструкция гейта).
- Рёбра: обычные + **loop-edge** (max_iters, поведение при исчерпании:
  эскалация-гейт). Циклы разрешены только через loop-edge.
- `entry` — пометка стартовой ноды (ровно одна).

## UI

- Канва xyflow: drag нод, соединение рёбер, мини-карта, автолейаут
  (dagre) по кнопке, snap grid.
- Инспектор ноды (правая панель): все ручки этапа формой; промпт-шаблон —
  редактор с подсветкой плейсхолдеров `{{...}}` и их автодополнением
  (список доступных из движка T-17).
- Инспектор loop-edge: max_iters, текст эскалации.
- Превью «как будет выглядеть ран» (read-only граф).

## Валидация (при сохранении, блокирующая)

- Ровно один entry; все ноды достижимы из entry; нет висячих рёбер.
- Циклы только через loop-edge (проверка: удалить loop-рёбра → граф ацикличен).
- Обязательные поля нод заполнены; artifact-контракты этапов согласованы
  (этап потребляет артефакт, который производится ранее).
- Плейсхолдеры в промптах — только известные.

## Сохранение

- Сохранить = новая версия (T-21); «клонировать» = копия с новым именем.
- Старые раны продолжают ссылаться на свою версию (неизменяемость).

## Acceptance

- Можно собрать пайплайн M1-дефолта с нуля в редакторе и запустить его.
- Невалидные конфигурации не сохраняются, ошибки подсвечены на канве.
- Редактирование версии, на которую ссылается активный ран, не влияет
  на ран.
