# T-16 Экраны проектов, пайплайнов, создание рана

Статус: done (2026-08-17) · M1 · зависимости: T-13

## Цель

IA по D-60: Проекты → Проект (селектор пайплайна) → Ран.

## Экран «Проекты»

- Список: имя, путь, ветка, активный ран (мини-статус + пульс), бейдж
  открытых гейтов. Live-обновление через WS.
- Добавление проекта: выбор локального git-репозитория (в Tauri — нативный
  диалог выбора каталога; в браузерном фолбэке — ввод пути с валидацией
  через API).
- Настройки проекта: default_branch, ide_command (goland/code/cursor/
  свой), notify_tg default.

## Экран «Проект»

- Сверху — селектор пайплайна (табы или дропдаун; мини-граф пайплайна в
  табе). Запоминается последний выбранный (per project, localStorage).
- Под ним — раны выбранного пайплайна: карточки/строки: задача (первая
  строка), состояние (мини-граф с прогрессом), длительность, токены,
  время создания. Фильтр по состоянию. Клик → экран рана (T-14).
- Кнопка «Новая задача» → форма запуска.

## Форма «Новая задача»

- Текст задачи (многострочный, markdown-описание ок).
- Глубина: quick/standard/deep (с подсказками, что делает каждый).
- Ветка: «новая от <default>» (автоимя `glamor/<slug>`, показать preview)
  / «новая с именем» / «существующая ветка» (select).
- Чекбокс «уведомлять в TG» (default из настроек проекта).
- Превью пайплайна: мини-граф + триплеты этапов (harness/model/effort) —
  read-only в M1.
- Сабмит → `POST /runs` с Idempotency-Key (двойной клик/ретрай безопасны)
  → редирект на экран рана. Ошибки preflight (dirty checkout, locked
  branch) — человекочитаемо со списком файлов/ветки (T-10).

## Acceptance

- Полный путь пользователя: добавить проект → выбрать пайплайн → создать
  задачу → попасть на экран рана.
- Ошибка «грязный чекаут» показывает список мешающих файлов и кнопку
  «всё равно запустить» (force).
- Состояния списков живые (WS), без ручного рефреша.

### Дополнение 2026-08-17 (fix-task-2: П.5, П.3, фронт, субагент)

- **П.5 (табы пайплайнов по версиям) — решение**: таб = пайплайн (имя),
  внутри таба — переключатель версии (`<select>`, виден только когда
  версий > 1; пометка «(последняя)»). Клик по табу активирует последнюю
  версию; раны по-прежнему фильтруются строго по выбранной версии

  версий без доп. запросов — переключатель показывается по числу версий
  (проще и без лишних fetch'ей). localStorage помнит выбранную версию,
  как раньше. Группировка — чистая `groupPipelinesByName` в
  `lib/pipelines.ts` (vitest, 4 шт.).
