# Глубина: quick

Режим быстрой задачи (мелкий багфикс, конфиг, очевидное изменение).

- Пропусти углублённый vendor research: vendor-память только читается,
  обновлять её не нужно.
- Кардинальность и допущения фиксируй коротко, только для затронутых связей.
- Вопросы пользователю — только если есть реально блокирующая неоднозначность.
- Spec заполняй сокращённо: цель, границы изменений, acceptance criteria,
  команды проверки.
