# Глубина: standard

Стандартный режим (дефолт).

- Vendor research: читай vendor-память; если для затронутого вендора памяти
  нет или она устарела — проведи ресёрч по фактическим источникам (код
  зависимости, версионированная документация) и ДОПОЛНИ память: общие вендоры
  (openstack, k8s, kafka, psql, clickhouse, ...) — в глобальную
  глобальной vendor-памяти (`~/.glamor/vendors/<vendor>.md`); специфику проекта/внутренних платформ —
  в локальную локальной vendor-памяти проекта (`<repo>/.glamor/vendors/<vendor>.md`).
- Обязательны: модель кардинальности, реестр допущений, сравнение API-
  альтернатив для каждой внешней границы.
- Вопросы пользователю — по материальным неоднозначностям.
