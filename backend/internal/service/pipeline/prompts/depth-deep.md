# Глубина: deep

Полный режим (новая фича, новая интеграция, CLoop/operator/controller,
рискованные изменения).

- Всё из standard, плюс:
- Полный vendor research по каждой затронутой границе с обновлением памяти
  (глобальной для общих вендоров, локальной для проектной специфики), даже
  если память уже есть — проверь актуальность версий.
- Матрица краевых случаев: ноль родительских сущностей, ноль/одна/много
  связанных сущностей, частичный отказ, изоляция отказа одной сущности от
  остальных, retry, отмена контекста/остановка процесса.
- Для SALT/CLoop явно разреши: lifecycle ресурса, desired-vs-actual,
  ownership keys, finalizers/очистку, status/conditions/reasons, bootstrap,
  requeue/retries, семантику доставки событий.
- Вопросы пользователю обязательны по каждому открытому допущению,
  влияющему на полноту или корректность.
- Тест-план обязан покрывать кардинальность 0, 1 и N, а не только happy path.
